Taco Bell Mode · Ambition Spectrum

Team Onboarding

Same job for every column: get new ops hires productive on their first three workflows without full-time senior shadowing. Only ambition level changes.

MILD Safe / conventional HOT Clear step up FIRE Ambitious + eng lift DIABLO Stretch / 200%
Mild

Checklist Home

Safest shippable path using patterns managers already know.

A single onboarding page with a linear checklist of the three core workflows, linked docs, and a “mark complete” control. Manager sees a simple progress %.

UX bets

  • One screen: Today’s tasks + linked SOP
  • Manual complete / reopen by new hire
  • Manager widget: % done this week
  • Reuse existing table + button components

Craft notes

  • Static layout, system type, no custom motion
  • Empty / loading / error via existing patterns

Tradeoff: Fast to ship; little coaching or verification that they actually learned.

Build cost: ~2–4 days · low risk

Hot

Guided Tracks

Noticeable upgrade—structured tracks without inventing a new product.

Three role tracks with step-by-step modules (read → practice sandbox → quiz gate). Progress is automatic where possible; managers get per-track status.

UX bets

  • Track picker → module list → step detail
  • Lightweight quiz gate before “certified”
  • Manager board: who is stuck / overdue
  • Soft celebratory complete state

Craft notes

  • Tasteful page transitions; progress ring
  • 1–2 new step-list components

Tradeoff: Better learning signal; still mostly content + forms, not live coaching.

Build cost: ~1–2 weeks · moderate content + quiz work

Fire

Live Shadow Mode

Ambitious: practice inside real UI with safe rails and new interaction model.

Split-view coach: left rail narrates the workflow while the right pane is a sandboxed clone of the live ops tool. Actions are scored; blockers summon a human coach.

UX bets

  • Coach rail + sandbox app surface
  • Highlight targets; validate correct actions
  • “Call a coach” escalations with context dump
  • Manager timeline of attempts + friction points

Craft notes

  • Orchestrated highlights, spotlight, micro-feedback
  • New sandbox shell + instrumentation hooks

Tradeoff: High learning fidelity; needs sandbox fidelity and event plumbing.

Build cost: ~1–2 sprints · sandbox + telemetry risk

Diablo

Adaptive Co-Pilot

Stretch moonshot—onboarding becomes a persistent AI co-worker, not a course.

Always-on co-pilot that watches real (permissioned) sessions, intervenes only at risk moments, generates personalized drills overnight, and grades readiness for unsupervised shifts. Explicitly aspirational.

UX bets

  • Ambient assist in live tool, not a separate LMS
  • Risk-triggered interventions + undo-safe actions
  • Overnight drill generator from yesterday’s misses
  • Manager “readiness score” with explainability

Craft notes

  • Cinematic but calm interventions; voice optional
  • Model eval harness, privacy review, policy engine

Tradeoff: Brand-defining if it works; multi-sprint R&D and compliance load.

Build cost: multi-sprint stretch · AI + privacy + eval risk

Constants locked: SSO · role-based tasks · manager visibility · Chrome · WCAG AA · existing design tokens · no new mobile app.

Mix ideas: Hot tracks + Fire sandbox for one workflow · Mild checklist now, Fire later · Fire UI with Diablo readiness scoring only.
