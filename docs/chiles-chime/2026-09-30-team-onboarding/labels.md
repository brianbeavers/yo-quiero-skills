# Chiles Chime Labeling: trial (Figma fallback)

Figma MCP was not available for this trial, so this is the rename map + legend
fallback from `chiles-chime-labeling`. In a real run with Figma connected, these
become label groups above each frame (24px gap), not overlays on the art.

## Spectrum legend

| Heat | Meaning |
| --- | --- |
| **Mild** | Safe / minimal change / conventional path |
| **Hot** | Clear step up, still familiar |
| **Spicy** | Ambitious craft + eng lift |
| **Inferno** | Stretch: swing for the fences |

## Frame to heat mapping

Assumes four concept columns from the mode trial board.

| Target (suggested Figma name) | Heat | Concept | Why this heat |
| --- | --- | --- | --- |
| `Mild - Checklist Home / Overview` | Mild | Checklist Home | Simple checklist. Easy to ship. Familiar to everyone. |
| `Hot - Guided Tracks / Overview` | Hot | Guided Tracks | More structure, still a normal product shape. |
| `Spicy - Live Practice / Overview` | Spicy | Live Practice | Practice in a fake version of the real tool, with coaching beside it. |
| `Inferno - Always-on Coach / Overview` | Inferno | Always-on Coach | Big swing. Help shows up in the live tool, not in a separate course. |
